# 材料分组与后续拆仓

[返回首页](../README.md)

先以一个文档型作品集组织材料；每个主题达到可公开、可运行、可评测后，再拆成独立实现仓库。

| 已有材料线索 | 当前归组 | 原因 |
| --- | --- | --- |
| FastWAM 训练报告、0–40 update 图、RoboTwin/RLinf 桥接 | FastWAM 后训练 | 训练、适配与评测可以围绕同一问题展开，但不同分支不共享结果 |
| 阶段坐标、Ruler-RECAP、LingBot 训练/评测记录 | 奖励与动作一致性 | 可以完整讲清一个假设、实施版本、负结果及下一步验证 |
| 静态/动态记忆、对象事件历史 | 长期记忆 | 共同问题明确，具体版本和指标需要分别绑定 |
| Temporal critic、真实分支偏好、World-Preview Bellman | 世界预测与动作选择 | 已核对有明确前后动机的历史报告；保留负结果与不显著结果 |
| SAC-Flow-inspired 五轮方案及其他 World-Q 变体 | 后续候选 | 不将其他变体的设计与已核对版本的指标混用 |
| ICL、IDM/action probe、VLM pilot | 后续候选 | 已定位迁移材料，最终结果与个人贡献待另行审阅 |
| 模型下载、缓存、虚拟环境、依赖目录 | 不作为独立项目 | 环境文件不能单独证明研究贡献 |

拆仓条件：责任与许可明确、有独立的问题定义、有最小运行路径、结果可追溯、与其他项目边界清楚。研究负结果也可以形成案例，但不能伪装成已解决的问题。
