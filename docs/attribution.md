## 发布前应补齐

- 每个上游的官方地址、精确版本/commit、许可证及引用方式。
- 本人新增或修改的文件、必要 diff，以及合作贡献说明。
- 实习期间产物的公开授权范围：代码、指标、图、日志、视频分别确认。
- 对外描述与公司、团队、导师等相关方要求是否一致。

不把 Fork 等同于原创，不把上游项目 Star 数当成个人成果，不把目录中全部历史 run 数当成个人实验数量。

仓库暂未选择开源许可证，也未复制上游或公司训练源码。未核验权利前，不自动套用 MIT/Apache 等许可。后续公开代码时应保留必要版权与许可声明。

本次新增的文档检查工具应单独说明来源；它不属于此前实习或科研期间的交付。
